# GLOSSARY — 《交互设计精髓》337 术语词典

| 术语 | 337 答题解释 |
|---|---|
| 交互设计 | 设计产品行为的学科，关注用户如何理解、操作、反馈和完成目标。 |
| 目标导向设计 | 以用户目标为中心，通过研究、人物模型、场景和框架推导产品行为的方法。 |
| 用户目标 | 用户使用产品真正想达成的结果，通常比具体功能更稳定。 |
| Persona / 人物模型 | 基于用户研究抽象出的典型用户，用于指导设计决策。 |
| Scenario / 场景 | 用户在特定情境下为达成目标而与产品互动的过程描述。 |
| 心智模型 | 用户对产品如何工作形成的主观理解。 |
| 实现模型 | 系统内部真实运行方式，通常不应直接暴露给用户。 |
| 认知摩擦 | 用户理解、判断和操作时遇到的心理阻力。 |
| 交互框架 | 产品整体行为结构，包括对象、导航、工作流、界面区域和反馈方式。 |
| 反馈 | 系统对用户操作或状态变化给出的响应。 |
| 容错 | 产品帮助用户预防错误、发现错误、撤销错误和恢复状态的能力。 |
| 一致性 | 产品在视觉、操作、术语和行为规则上保持稳定，降低学习成本。 |
