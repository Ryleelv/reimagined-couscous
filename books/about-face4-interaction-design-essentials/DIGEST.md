# DIGEST — 不读全书也要掌握的《交互设计精髓》

## 1. 核心公式

```text
用户研究 → 用户目标 → 人物模型 → 使用场景 → 任务流程 → 交互框架 → 界面行为 → 测试迭代
```

337 答题时，只要遇到“设计某产品”“评价某系统”“优化某体验”，都可以从这条链路展开。

## 2. 最重要的转变

交互设计不是把界面做漂亮，而是设计产品如何行动、如何响应、如何帮助用户完成目标。工业设计中的智能硬件、公共终端、服务系统和车载界面，都可以用这套逻辑分析。

## 3. 答题万能段

目标导向设计强调从用户真实目标出发，通过用户研究理解用户行为、动机与使用情境，再建立人物模型和典型场景，将抽象需求转化为任务流程、功能优先级和交互框架。其价值在于避免功能堆砌和自我参考设计，使产品更符合用户心智模型，降低认知摩擦，提高使用效率和满意度。

## 4. 工业设计迁移

- 智能药盒：目标不是“设置提醒”，而是“让患者安全、准时、低负担服药”。
- 车载系统：目标不是“功能丰富”，而是“驾驶中快速、少分心地完成关键操作”。
- 自助终端：目标不是“展示所有业务”，而是“让不同经验水平的人快速完成办理”。
- 智能家居：目标不是“设备联动复杂”，而是“让家庭成员自然理解和控制环境”。

## 5. 考前只背这 6 句

1. 交互设计的核心是产品行为，而不是界面装饰。
2. 目标导向设计从用户目标而非系统功能出发。
3. 人物模型让设计对象具体化，避免弹性用户。
4. 场景把用户、目标、环境和任务连接起来。
5. 好的交互应符合用户心智模型，减少认知摩擦。
6. 反馈和容错决定用户是否能理解系统并从错误中恢复。
