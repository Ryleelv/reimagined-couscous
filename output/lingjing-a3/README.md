# 岭境 A3 学习示意图

三张文件均为 **A3 横版（420 × 297 mm）SVG**，按 300 dpi 的 4961 × 3508 画布制作，可直接在浏览器、Illustrator、Inkscape 或 Affinity Designer 中打开、打印或导出 PDF/PNG。

- `01-design-analysis.svg`：题目分析、用户痛点、体验与商业闭环。
- `02-design-sketches.svg`：形态推演、关键创新与草图表达要点。
- `03-product-system.svg`：主体产品、三视图、UI、场景与工作原理。
- `index.html`：三页缩略预览和逐页打开入口。
- `figma-plugin/`：将三张 SVG 一次性导入当前 Figma 页面的本地插件。

## 推荐阅读顺序

1. 第 1 页先回答“为什么设计”：用户、痛点、设计目标与商业闭环。
2. 第 2 页回答“方案如何形成”：四条形态路线、核心创新与最终取舍。
3. 第 3 页回答“产品如何工作”：主体造型、结构、UI、原理和市场价值。

## 导入 Figma

打开 Figma 桌面版，选择 **Plugins → Development → Import plugin from manifest…**，然后选择 `figma-plugin/manifest.json`。运行“岭境 A3 画板导入器”并一次选择三张 SVG，即可自动横向排入当前页面。详细步骤见 `figma-plugin/README.md`。

设计对象为原创概念“岭境 LingJing”双态文化眼镜；参考图仅用于理解轻量化混合现实眼镜的产品类别，不复刻其外观。
